* [[Unreleased]]

* [[0.3.0]] - 2026-07-16

** Added
- Ticket assignee switching via =go-jira-assign=
  - Presents the users assignable to the ticket, fetched live from Jira, so
    each project's permissions are honored automatically
  - Offers "Assign to me" first, flipping to "None" to unassign when the ticket
    is already assigned to you
  - Available in the ticket view and board buffers (=C-c C-a=), as an Embark
    action, or on a ticket number at point
  - New module =go-jira-assign.el=

** Technical
- Assignee changes use the go-jira REST bridge (=jira request
  .../assignee --method PUT=); unassigning sends =accountId: null=
- Buttercup coverage for user parsing, candidate ordering, the me/none default
  flip, request payloads and Embark target handling

* [[0.2.0]] - 2026-07-15

** Added
- Ticket status (workflow transition) switching via =go-jira-change-status=
  - Presents the transitions valid from the ticket's current state, fetched
    live from Jira, so each project's workflow is honored automatically
  - Available in the ticket view and board buffers, as an Embark action, or on
    a ticket number at point
  - New module =go-jira-status.el=
- Status-based colorization of issue keys in the ticket view, board, and hover
  popup, derived from Jira's status category (To Do / In Progress / Done)
  - Optional =go-jira-status-face-alist= for per-status color overrides
  - Faces =go-jira-status-todo-face=, =go-jira-status-in-progress-face=,
    =go-jira-status-done-face= and =go-jira-status-default-face=
- Hover popup now shows the ticket status alongside the summary
- Comment support for Jira tickets with overlay-based UI
  - =go-jira-add-comment= command bound to =C= in both view and board modes
  - Inline comment composition using Org-mode markup
  - Automatic conversion from Org-mode to Jira wiki markup
  - Submit with =C-c C-c=, abort with =C-c C-k=
- Bidirectional markup conversion in =go-jira-markup.el=
  - =go-jira-markup-from-org= function converts Org-mode to Jira markup
  - Support for headings (h1-h6), bold, italic, underline, strikethrough
  - Support for inline code, code blocks with language specification
  - Support for numbered lists, bulleted lists, and nested lists
  - Support for links with and without descriptions
  - Support for example blocks
- New module =go-jira-comment.el= for comment functionality
- Test suite for Org-to-Jira conversion in =test/go-jira-comment-tests.el=
- Comprehensive documentation in =COMMENT-FEATURE.md=

** Changed
- Eldoc/popup now fetches full ticket JSON (summary and status) instead of the
  summary alone; a status change invalidates the ticket's cached popup entry so
  its color refreshes immediately
- Updated =go-jira-view-mode= help message to include comment command
- Updated =go-jira-board-view-mode= help message to include comment command
- Updated =readme.org= with comment feature documentation

** Technical
- Status transitions use the go-jira REST bridge (=jira request .../transitions=)
- Status colors resolve via Jira =statusCategory= and are applied through a
  font-lock keyword so they survive Org heading refontification
- Embark actions read the target ticket via their first minibuffer prompt, so
  the target is injected there rather than into a later picker
- Buttercup coverage for transition parsing, colorization, faces, Embark target
  handling and popup cache invalidation
- Comment submission uses temporary files to avoid shell escaping issues
- Placeholder-based protection mechanism prevents conversion conflicts
- Overlay management inspired by gptel's tool-use interface
- Automatic view refresh after successful comment submission

* [[0.1.0]] - Initial Release

** Added
- =go-jira-view-ticket= - View Jira tickets in Org-mode format
- =go-jira-display-board= - Browse and view Jira boards
- =go-jira-search= - Search Jira issues with consult integration
- Jira markup to Org-mode conversion
- Eldoc integration for showing ticket summaries at point
- Embark integration for ticket numbers
- Support for subtasks and linked items
- Comment viewing (read-only)
